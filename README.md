# Infinity for iPad / iPhone

1. In your GitHub repository (Public), upload every file in this folder except `build-ios.yml` (replace the old ones).
2. Open `.github/workflows/build-ios.yml` on GitHub, click the pencil, select all, paste the text from `build-ios.yml`, and commit.
3. When the Actions run shows a green tick, download `Infinity-ipa`, unzip it, and install `Infinity.ipa` with Sideloadly.
4. Set up accounts and sync with ACCOUNT-SETUP.md (optional).
